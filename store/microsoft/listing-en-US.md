# Aurora Music — Microsoft Store

## Product name

Aurora Music

## Short description

Your music, your rules. Discover, organize, and share music in a modern experience powered by YouTube.

## Description

Aurora is an independent, modern, and social music experience. Search for music, build your library, create playlists, see what friends are listening to, and control playback from an interface designed for desktop.

Playback uses the official YouTube player. You can explore Aurora without signing in and optionally connect a Google account when you want access to your YouTube library.

Aurora Connect lets invited devices join a shared session. Community profiles, following, and collaborative playlists turn listening into a shared experience while profile settings keep social and musical data under your control.

Aurora for Windows runs in its own window, integrates with Windows media controls, adds Start menu shortcuts, and receives updates automatically.

Aurora is an independent project and is not affiliated with YouTube, Google, or Spotify.

## Features

- Search and playback through the official YouTube player
- Personal library, likes, queue, and playlists
- Profiles, following, and collaborative playlists
- Shared listening sessions with Aurora Connect
- Windows media control integration
- Lightweight installation and automatic updates
- Responsive interface for compact windows and large screens
- Guest mode for exploring before sign-in
